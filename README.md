Movie 🎬

A simple Movie Management application built with Python, PySide6 and SQLite.

Features

- Add movies
- Edit movie information
- Delete movies
- View movies in a table
- Store movie information in SQLite database

Information

Each movie includes:

- Name
- Author
- Year
- Genre
- Rating

Technologies

- Python
- PySide6
- SQLite

How to Run

Run the following command:

python main.py
